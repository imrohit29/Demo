DEVELOPMENT PLAN

PHASE 1:
Build every screen and dropdown in frontend.

PHASE 2:
Add backend separately, for example:
backend/
├── server.js
├── routes/
├── controllers/
├── models/
├── config/
└── database/

PHASE 3:
Connect frontend modules to backend APIs.

PHASE 4:
Connect database.

This keeps frontend and backend separate and makes future changes easier.
